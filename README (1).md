# অটো নিউজ কার্ড — ধাপ ১

খবরের লিংক দিলে হেডলাইন ও ছবি নিজে বসে যায়, নিজের লোগো ও ব্র্যান্ড রঙসহ প্রফেশনাল নিউজ ফটোকার্ড তৈরি হয়।
সাধারণ HTML/CSS/JS + তিনটি Netlify Function। কোনো বিল্ড টুল বা প্যাকেজ ইনস্টল লাগে না।

## ধাপ ১-এ যা যা আছে

- নিউজ লিংক থেকে হেডলাইন ও (সর্বোচ্চ ৪টি) ছবি আনা, অথবা নিজে ছবি আপলোড
- `*তারকা*` চিহ্ন দিয়ে শব্দ রঙিন করা + এক ট্যাপে অটো হাইলাইট
- ৮টি টেমপ্লেট: ব্রেকিং নিউজ, টিভি স্টাইল, পত্রিকা স্টাইল, অনলাইন পোর্টাল, খেলার খবর, উক্তি কার্ড, শোক সংবাদ, ছবি ছাড়া কার্ড
- ৪টি সাইজ: ১:১, ৪:৫, ১৬:৯, ৯:১৬ (স্টোরি/রিল কভার)
- ব্র্যান্ড সেটআপ: প্রতিষ্ঠানের নাম, লোগো, ওয়েবসাইট, মূল রং ও হাইলাইট রং (একবার দিলে ব্রাউজারে সেভ থাকে)
- ৫টি বাংলা ফন্ট, লেখার সাইজ, ছবির অবস্থান ও জুম
- Gemini AI: ৩টি হেডলাইন প্রস্তাব + ফেসবুক ক্যাপশন + হ্যাশট্যাগ
- PNG / JPG ডাউনলোড, মোবাইলে সরাসরি শেয়ার

## ফোল্ডার

```
public/                 ওয়েবসাইট: index.html, style.css, app.js, draw.js, templates.js, render.js, favicon.svg
netlify/functions/      সার্ভার অংশ: fetch-news.js, proxy-image.js, ai.js, safe.js
netlify.toml            Netlify সেটিং
```

## GitHub ও Netlify-তে চালু করার নিয়ম

1. **GitHub-এ নতুন repository** খুলুন (যেমন `auto-news-card`)।
2. **ফাইল আপলোড (ফোনেও হয়):** GitHub শুধু ফাইল আপলোড করতে দেয়, ফোল্ডার নয়। তাই এভাবে করুন:
   - repository-র মূলে *Add file → Upload files* দিয়ে `netlify.toml` ও `README.md` আপলোড করে Commit করুন।
   - *Add file → Create new file* চাপুন। ফাইলের নামের ঘরে লিখুন `public/start.txt` (স্ল্যাশ দিলে `public` ফোল্ডার নিজেই তৈরি হয়), ভেতরে যেকোনো একটা অক্ষর লিখে Commit করুন।
   - আবার *Create new file* দিয়ে নাম লিখুন `netlify/functions/start.txt`, ভেতরে একটা অক্ষর দিয়ে Commit করুন।
   - এবার repository-তে `public` ফোল্ডার খুলুন → *Add file → Upload files* → ৭টি ফাইল একসাথে বেছে নিন (`index.html`, `style.css`, `app.js`, `draw.js`, `templates.js`, `render.js`, `favicon.svg`) → Commit।
   - তারপর `netlify` → `functions` ফোল্ডার খুলে একইভাবে ৪টি ফাইল আপলোড করুন (`fetch-news.js`, `proxy-image.js`, `ai.js`, `safe.js`) → Commit।
   - শেষে চাইলে দুটি `start.txt` মুছে দিতে পারেন (না মুছলেও সমস্যা নেই)।
3. **Netlify** → *Add new site → Import an existing project* → GitHub বেছে repository সিলেক্ট করুন।
   Build command ফাঁকা রাখুন; Publish directory `public` (netlify.toml থেকে নিজেই আসবে)।
4. **AI চালু করতে:** Netlify → Site configuration → *Environment variables* → যোগ করুন:
   - `GEMINI_API_KEY` = আপনার Google AI Studio API Key (https://aistudio.google.com/apikey)
   - (ঐচ্ছিক) `GEMINI_MODEL` = মডেলের নাম। না দিলে `gemini-2.5-flash` ব্যবহার হবে।
     Google মডেলের নাম বদলালে বা AI-তে "মডেল" সংক্রান্ত ভুল দেখালে এখানে বর্তমান Flash মডেলের নাম বসান।
   - (ঐচ্ছিক) `ALLOWED_HOSTS` = `আপনার-সাইট.netlify.app` — দিলে অন্য কেউ আপনার সাইটের ফাংশন ব্যবহার করতে পারবে না। কাস্টম ডোমেইন থাকলে কমা দিয়ে সেটাও দিন।
5. Environment variable বদলানোর পর *Deploys → Trigger deploy* করুন।
6. সাইট খুলে ডানের উপরের **ব্র্যান্ড সেটআপ** থেকে নাম, লোগো ও রং দিন।

> API Key কখনো `public/` ফোল্ডারে বা GitHub-এ লিখবেন না। শুধু Netlify-র environment variable-এ রাখুন।

## জেনে রাখুন

- কিছু নিউজ সাইট বাইরের সার্ভারকে আটকে দেয় (Cloudflare ইত্যাদি)। তখন "খবর আনা যায়নি" দেখাবে; হেডলাইন ও ছবি নিজে দিয়ে দিন।
- Netlify ফ্রি প্ল্যানে প্রতিটি ফাংশন সর্বোচ্চ ১০ সেকেন্ড চলে এবং মাসে সীমিত সংখ্যক কল পাওয়া যায়।
- ফন্ট Google Fonts থেকে আসে, তাই ইন্টারনেট লাগবে।
- ছবি ও লেখা ব্রাউজারেই প্রসেস হয়; সার্ভারে শুধু লিংক পড়া, ছবি প্রক্সি ও AI অনুরোধ যায়।
- খবরের ছবি ও লেখার কপিরাইট নিয়ে সতর্ক থাকুন: যে ছবি ব্যবহারের অধিকার আপনার আছে সেটাই ব্যবহার করুন।
